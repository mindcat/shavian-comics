# shavian fonts

All fonts designed by Haley Wakamatsu.

Backlog Shavian looks the most like the original calvin & hobbes text, but
you have to get used to using crossbars to identify ascenders and descenders.

Stampatello Faceto is the most legible, but is just a handwritten font.

Banter is not great for Calvin & Hobbes, but might be useful for other comics?
